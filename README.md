# CopyBot 3D Print STLs

Printable STL models matching the CopyBot merch design (robot figurine, keychain, nameplate).

## Files

| File | Size | Description |
|------|------|-------------|
| `CopyBot_Robot.stl` | ~50 mm tall | Mini robot figurine (antenna, blue-eye recesses, chest plate) |
| `CopyBot_Keychain.stl` | 40×40 mm | Keychain tag with robot face logo + "CopyBot" text + keyring hole |
| `CopyBot_Nameplate.stl` | 52×16 mm | Badge / nameplate with raised "CopyBot" lettering |

## Print settings (recommended)

- **Material**: PLA or PETG
- **Layer height**: 0.16–0.2 mm
- **Infill**: 15–20%
- **Supports**: Usually not needed (robot stands flat; keychain & nameplate print face-up)
- **Multi-color tip**: Pause at eye layers for blue filament, or paint after print

## Sizes

- Robot: ~31.5 × 14 × 49 mm
- Keychain: 40 × 40 × 5.3 mm  
- Nameplate: 52 × 16 × 4.3 mm

Scale freely in your slicer if you want larger/smaller.

## Source

Parametric models generated with CadQuery to match the CopyBot product photo.
